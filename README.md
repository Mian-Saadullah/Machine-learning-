# Machine Learning Practice 🚀

Welcome to my Machine Learning repository! This project contains hands-on implementations of core ML algorithms built using Python and Scikit-Learn.

## 📁 Contents
* **`ml.py`**: Contains implementations for:
  1. **Linear Regression**: Predicting student marks based on study hours.
  2. **Naïve Bayes Classifier (GaussianNB)**: Predicting student results (Pass/Fail) based on study hours and marks, including custom input prediction.

## 🛠️ Tech Stack
* Python
* Pandas
* Scikit-Learn
